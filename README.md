One line of famous last words, a tombstone epitaph, built for the
[make.fun](https://make.fun) bounty
"Famous Last Words: The Funniest Epitaph".

> Tell them I died doing what I loved: ignoring the check engine light.

`main.py` (Python 3, standard library only) writes the epitaph to
`/output/entry.txt`, deterministically.
